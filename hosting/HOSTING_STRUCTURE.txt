BKDZITI FREE HOSTING STRUCTURE
==============================

Directory Layout:
hosting/
├── index.html              (Main hosting landing page - START HERE)
├── README.md               (User guide and instructions)
├── HOSTING_STRUCTURE.txt   (This file)
├── example-site/           (Template for users to copy)
│   ├── index.html         (Template homepage)
│   ├── style.css          (Professional styling)
│   └── script.js          (Example JavaScript)
│
├── client-1/              (Hosted websites below this line)
├── client-2/
├── portfolio-project/
├── their-website/
└── ... (add more as needed)

HOW IT WORKS:
=============

For Users/Clients:
1. Copy the example-site/ folder
2. Rename it to their site name: client-name/
3. Edit index.html with their content
4. Customize style.css with their branding
5. Add/modify script.js as needed
6. Site goes live at: bkdziti.com/client-name/

File Structure Best Practice:
client-name/
├── index.html
├── about.html
├── services.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   ├── videos/
│   └── documents/

IMPORTANT NOTES:
===============
- Always use relative paths for internal links
- Link back to BKDziti: href="../../index.html"
- Keep file sizes reasonable (under 50MB total)
- Use meaningful folder names (no spaces, use hyphens)
- All files should be UTF-8 encoded

EXAMPLES OF GOOD LINKS:
======================
Within their site: href="about.html" or href="css/style.css"
Back to main: href="../../index.html"
To main store: href="../../store/index.html"

EXAMPLES OF BAD LINKS:
====================
Absolute paths: href="http://bkdziti.com/client-name/about.html" (WRONG)
Wrong directory: href="../../../about.html" (WRONG)
Missing extensions: href="about" (WRONG)
